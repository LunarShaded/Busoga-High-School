# 🎓 Busoga High School Website

A modern and responsive school website template designed for **Busoga High School** located in Uganda, Kamuli.

This project was created as a ready-to-use frontend template that can be easily connected to any backend or CMS. All content is currently placeholder data and can be fully customized to match the school's real information, images, and branding.

---

You can visit the site using this link:

https://lunarshaded.github.io/Busoga-High-School/

## ✨ Features

- 📱 Fully responsive design for desktop, tablet, and mobile devices
- 🧭 Smooth navigation header with anchor links to all sections
- 🎨 Modern green and white color palette
- 🏫 Professional school-focused layout
- 🗺️ Embedded Google Maps location
- 📰 News and events section
- 📬 Contact section with school information
- 🔧 Easy to customize and extend
- ⚙️ Ready for backend integration

## 📂 Website Sections

The website consists of **7 main sections**:

### 🏠 Home
A welcoming hero section featuring the school title, a short introduction, and call-to-action buttons.

### ℹ️ About
Overview of the school's mission, vision, and background.

### 📚 Academics
Information about subjects, curriculum, and educational programs.

### 📝 Admissions
Details about the admission process and requirements.

### 📰 News & Events
Latest announcements, school updates, and upcoming events.

### 📞 Contact
School contact information and an embedded Google Map.

### 🦶 Footer
Additional links, copyright information, and social media placeholders.

- Home

- Academics

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/LunarShaded/Busoga-High-School.git
cd Busoga-High-School
```

### 2. Install Dependencies

```bash
npm install
```
### 3. Start Development Server
```bash
npm run dev
```

Visit:
http://localhost:5173

---

## 📦 Build for Production

```bash
npm run build
```

```bash
npm run preview
```
